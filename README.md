#Equipo 2
Este es el repositorio del equipo 2 para la actividad GitHub 3 de la asignatura de proyecto intermodular.

En este repositorio se muestra un index.html que conduce a 4 páginas html. Cada una de estas páginas contiene la sinopsis de una serie. 

##Miembros:
* Al Hayy Castella
* Hugo Signes
* Iván Gómez Navarro
* Héctor Piquer Belda
* Alex Baicu
* David Alba

##Funciones de los miembros:
* Al Hayy Castella --> Creación y gestión del repositorio en GitHub
* Hugo Signes --> Creación del index.html
* Iván Gómez --> Página de Friends
* Héctor Piquer --> Página de Breaking Bad
* Alex Baicu --> Página de The 100
* David Alba --> Página de Lost
